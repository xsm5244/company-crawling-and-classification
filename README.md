# 规划企业数据采集与项目文本分类

面向城乡规划行业研究的 Python 数据处理项目，涵盖规划企业信息采集、项目记录整理、企业地址解析及规划项目文本分类。

项目累计处理超过 **16 万条数据**，已完成基于 **MacBERT** 的文本分类模型训练，目前仍在开展研究与结果分析。

> 本仓库整理了研究过程中使用的主要脚本，部分脚本保留本地路径及调试配置，运行前需要按实际环境调整。

## 项目目标

将分散的企业信息与项目文本整理为可供研究使用的结构化数据，支持规划企业业务类型及地域分布等分析。

主要工作包括：

- 从公开网站提取规划企业名单。
- 查询企业统一社会信用代码，关联企业信息。
- 采集企业项目记录及地址信息。
- 根据行政区划信息识别企业所属城市。
- 基于已标注文本训练分类模型，辅助识别未标注项目的规划类别。

## 研究进展

## 处理流程

```text
规划企业名单采集
        ↓
统一社会信用代码查询
        ↓
企业项目记录与地址采集
        ↓
数据整理与地址所属城市识别
        ↓
项目文本标注与数据集准备
        ↓
MacBERT 模型微调与验证
        ↓
未标注项目预测与人工复核
```

各阶段通过 CSV 文件衔接，目前需要手动核对文件路径及字段名称。

## 文本分类方法

### 输入与标签

模型将以下字段组合为输入文本：

- `company_name`：企业名称
- `tenderee`：招标单位
- `project_name`：项目名称

分类标签为 `规划实际类别`。标签非空的数据用于训练与验证，标签为空的数据用于预测。

输入示例：

```text
公司：某规划设计单位；招标单位：某项目业主；项目名称：某地区规划编制项目
```

### 模型与训练

基于预训练模型 `chinese-macbert-base` 进行多分类微调。当前脚本包含：

- 训练集与验证集划分。
- 稀有类别合并处理。
- 类别加权交叉熵损失。
- Macro F1 与 Weighted F1 评估。
- 模型、分词器及标签映射保存。

代码中的主要配置如下，可根据数据及设备情况调整：

| 参数 | 当前配置 |
| --- | --- |
| 验证集比例 | 15% |
| 最大输入长度 | 128 tokens |
| 训练轮数 | 3 |
| 学习率 | 2e-5 |
| 训练批次大小 | 16 |
| 随机种子 | 42 |

### 预测与复核

脚本输出预测类别、模型预测概率及 Top-3 候选类别，并根据阈值进行分流：

| 模型预测概率 | 标记 | 用途 |
| --- | --- | --- |
| ≥ 0.85 | `AUTO` | 高置信度预测 |
| ≥ 0.60 且 < 0.85 | `REVIEW` | 建议复核 |
| < 0.60 | `MANUAL` | 建议人工判断 |

上述阈值为当前脚本配置。模型预测概率不代表经过校准的正确率，分类结果仍需结合验证表现及人工抽查判断。

## 运行准备

### 1. 安装依赖

```bash
pip install pandas numpy playwright selenium torch transformers scikit-learn accelerate
playwright install chromium
```

Selenium 相关脚本还需要可用的 Chrome 浏览器及兼容的驱动环境。依赖版本尚未锁定，如遇接口差异，需要结合本地环境调整。

### 2. 修改配置

运行前请检查：

- 输入与输出文件路径。
- CSV 字段名称及编码。
- 浏览器安装位置。
- 本地 MacBERT 模型目录。
- 网站页面结构及元素定位方式。

`2cid_search.py` 当前保留了首条记录处理后退出的调试逻辑。正式批量运行前，需要调整该处 `return`，并确认输出保存正常。

### 3. 准备分类数据与模型

分类脚本需要包含以下字段的 CSV：

```text
company_name,tenderee,project_name,规划实际类别
```

模型当前按离线方式加载，需要提前准备预训练模型文件，并将 `LOCAL_MODEL_DIR` 指向实际目录。

### 4. 按阶段运行

```bash
python 1name_crawl.py
python 2cid_search.py
python 3crawl_information.py
python 4address_from_web
python 5company_address_dealwith.py
python 6nlp_based_chinese-macbert-base.py
```

以上为阶段顺序示意。脚本中的文件名、字段及路径尚未统一，不能未经配置直接连续执行。

## 分类输出

分类脚本配置了以下输出：

- `label_map.json`：类别与标签编号映射。
- `model/`：微调后的模型及分词器。
- `pred_unlabeled_with_confidence.csv`：预测类别、概率、候选类别及复核标记。
- `data_filled_all.csv`：填充预测类别后的数据表。

使用填充后的数据时，应保留预测明细，以区分人工标注与模型预测结果。
